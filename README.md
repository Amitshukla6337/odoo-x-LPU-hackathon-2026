# StockSense

## Inventory Management System

StockSense is a centralized inventory management system designed to
streamline stock-related operations within a business.

## Core Features

- User Authentication
- Inventory Dashboard
- Product Management
- Incoming Stock / Receipts
- Outgoing Stock / Deliveries
- Internal Stock Transfers
- Stock Adjustments
- Stock Ledger
- Low Stock Alerts
- Search and Filters
- Multi-Warehouse Support
